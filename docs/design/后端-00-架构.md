## 3. 分层职责与禁止项

| 层 | 职责 | 禁止 |
|---|---|---|
| Controller | 参数校验（`@Validated`）、取 `UserContext`、调 Service、包装 `R` | 禁止写业务分支、禁止直接调 Mapper、**禁止接收 `status` / `coupleId` 入参** |
| Service | 业务规则、事务边界（`@Transactional`）、跨表编排 | 禁止拼装 HTTP 响应体 |
| PlanStateMachine | 状态转移白名单校验 + 条件更新 | 禁止做通知、爱心值等副作用（由 Service 编排） |
| Mapper | 单表 CRUD 与统计 | 禁止写跨表业务逻辑（复杂聚合除外） |
| Job | 定时扫描 + **复用 Service 方法** | 禁止绕过 Service 直接改状态（否则漏掉通知/幂等） |

## 5. 主键生成（53bit 雪花）

**为什么不用自增**：公司 SQL 规范要求雪花 ID（见 `00-全局约定.md` D1）。
**为什么是 53bit 而不是标准 64bit**：`id` 会随接口返给小程序，JS 的 `Number` 只能精确表示 `2^53-1` 以内的整数。标准雪花 64bit 直接返回会**静默丢位**（末几位变 0），表现为"详情页拿到的 id 和列表页对不上"。选 53bit 是让前后端都不用做字符串化转换。

**位宽**：41 位毫秒时间 + 12 位序列 = 53 位。时间位可用约 69 年（自定纪元起），序列支持单毫秒 4096 个 ID。

```java
// common/util/IdUtil.java
public final class IdUtil {
    /** 自定义纪元 2026-01-01 00:00:00 (UTC+8)，41 位毫秒约可用到 2095 年 */
    private static final long EPOCH = 1767225600000L;
    private static final long SEQ_BITS = 12L;
    private static final long MAX_SEQ = (1L << SEQ_BITS) - 1;   // 4095
    private static long lastTime = -1L;
    private static long seq = 0L;

    private IdUtil() {}

    public static synchronized long nextId() {
        long now = System.currentTimeMillis();
        if (now < lastTime) {
            now = lastTime;              // 时钟回拨：沿用上次时间，不倒退
        }
        if (now == lastTime) {
            seq = (seq + 1) & MAX_SEQ;
            if (seq == 0) {              // 当毫秒序列耗尽，自旋到下一毫秒
                while ((now = System.currentTimeMillis()) <= lastTime) {
                    Thread.onSpinWait();
                }
            }
        } else {
            seq = 0L;
        }
        lastTime = now;
        return ((now - EPOCH) << SEQ_BITS) | seq;
    }
}
```

**接进 MyBatis-Plus**：MP 默认 `IdType.ASSIGN_ID` 走它自带的 64bit 雪花，必须替换生成器，否则前功尽弃。

```java
// config/MybatisPlusConfig.java
@Bean
public IdentifierGenerator identifierGenerator() {
    return entity -> IdUtil.nextId();     // 覆盖 MP 默认 DefaultIdentifierGenerator
}
```

实体上统一 `@TableId(type = IdType.ASSIGN_ID)`，**不要写 `IdType.AUTO`**（数据库已无自增）。

**必须验证的一点**：M0 建库后插一条记录，用 `curl` 拿 JSON 看 `id` 是否与库里一致。若不一致（末几位为 0），说明生成器没生效、还在走 64bit 默认实现。
