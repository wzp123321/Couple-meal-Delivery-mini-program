## 1. 页面 → 接口

| 页面 | 调用 | 时机 |
|---|---|---|
| `menu` | `GET /api/menu/list` | 进入 / 切换筛选 / 增删改后 |
| `menu` | `POST`·`PUT`·`DELETE /api/menu` | 底部弹层提交 / 长按操作面板 |
| `menu` | `GET /api/menu/profile` | 点顶部画像卡片，弹层打开时 |
| 发起页选择层 | `GET /api/menu/recommend` | 打开选择层时先展示推荐 |

## 2. 菜单库页（`pages/menu`）

| 区域 | 要点 |
|---|---|
| 筛选条 | 分类 Tab（全部/荤/素/汤/主食）+「只看爱吃」开关 + 「我加的 / TA 加的」切换 |
| 列表 | `dish-tag` 显示菜名 + 忌口色标；长按出操作面板（编辑 / 删除） |
| 新增 | 底部弹层（`bottom-sheet`），菜名输入 + 分类单选 + 忌口级别选择器 + 爱吃开关 |
| 空态 | `empty-state` type 对应「还没有菜，加上你们爱吃的吧」 |
| 画像入口 | 顶部卡片展示「最常点」「忌口 N 道」，点开进详情弹层 |

**忌口色标**（`../前端-00-基础设施.md §6`）：无/少吃 → 中性灰；不吃 → 暖橘描边；过敏 → 红底白字，且卡片上强制显示。

---

## 3. 菜单选择层（在发起页内）

- 多选，最多 10 道（对齐 `2003`）。
- 已选数量实时显示在底部「选好了（3/10）」。
- 命中 `avoid_level >= 2` 时立即在条目上标红，**提交时才弹 L3 强提醒**，不在选择时打断。
- 顶部推荐位来自 `/api/menu/recommend`，点即选中；推荐为空时整块隐藏，不留空壳。

---

## 4. 验收要点

对照 `openspec/changes/bootstrap-mvp/specs/menu-prefs/spec.md`：

- [ ] 三个筛选维度可叠加，切换后列表立即更新
- [ ] 过敏菜在列表与选择层都是红底白字，一眼可见
- [ ] 长按出操作面板，编辑弹层回填当前值
- [ ] 重名提交后提示「这道菜已经在菜单里了」（2002），弹层不关闭、内容不丢
- [ ] 选择层超过 10 道时禁止再选并提示
- [ ] 选择时不在条目标红以外打断，只在提交时弹一次强提醒

---

## 5. 易错点

| 坑 | 说明 |
|---|---|
| 增删改后不刷新列表 | 本地删了但没重新拉，筛选态下会错位。**统一重取列表** |
| 忌口标色只做在列表页 | 选择层同样要标红，否则用户在点菜时看不到风险 |
| 重名报错后清空表单 | 用户要重打一遍。**保留输入，只提示** |
| 选择层在选择时就弹强提醒 | 每点一道弹一次，体验灾难。**只在提交时弹一次** |
