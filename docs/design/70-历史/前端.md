# 70 历史 · 前端

> **OpenSpec**：`plan-history` · **里程碑** M5
> **页面**：`pages/history`（报告为页内卡片 + 弹层，不单独开页）
> **前置必读**：`../00-全局约定.md`、`../前端-00-基础设施.md`、`../01-通用机制.md`（状态语义）
> **接口契约**：见 `后端.md §2`
> **后端对应**：`后端.md`

---

## 1. 页面 → 接口

| 位置 | 调用 | 时机 |
|---|---|---|
| `history` 列表 | `GET /api/plan/history` | 进页 / 切筛选 / 触底加载 |
| `history` 月报卡 | `GET /api/report?scope=month` | 进页时并行拉取 |
| 年度回顾弹层 | `GET /api/report?scope=year` | 弹层打开时 |

---

## 2. 历史页（`pages/history`）

| 区域 | 要点 |
|---|---|
| 顶部筛选 | 状态 chips（全部 / 已完成 / 已取消 / 已过期）+ 角色切换（我点的 / 我带的） |
| 列表 | 复用 `plan-card` 组件，按 `plan_date` 倒序 |
| 状态视觉 | 已完成正常色；已取消/已过期整卡降透明度 + 灰色标签（不做删除线，太"账本感"） |
| 空态 | `empty-state`「还没有一起吃过的饭，从今天开始吧」 |
| 分页 | 触底加载下一页，无更多时显示「就这些啦」 |

---

## 3. 点击行为

| 状态 | 点击后 |
|---|---|
| 4 / 5 / 6 | 进详情页（只读态，无操作按钮） |
| 其他 | 理论上不会出现在历史里（今日的约定不进历史） |

---

## 4. 报告展示

| 区域 | 要点 |
|---|---|
| 月报卡 | 历史页顶部一张「上月小结」：你带了 n 次 / TA 带了 m 次、最爱菜、打卡天数；`planCount=0` 时整卡不渲染 |
| 年报入口 | 历史页右上「年度回顾」→ **弹层**展示，不单独开页（页面总数保持 12） |
| 文案 | 写「你带了 8 次，TA 带了 6 次」，不写「带饭次数统计表」——报告是回忆，不是报表 |

---

## 5. 验收要点

对照 `openspec/changes/bootstrap-mvp/specs/plan-history/spec.md`：

- [ ] 筛选 chips 与角色切换可叠加，切换后列表重头加载
- [ ] 已取消/已过期卡片降透明度 + 灰标签，无删除线
- [ ] 触底加载到底显示「就这些啦」，不再重复请求
- [ ] 月报 `planCount=0` 时整卡不渲染，不留空壳
- [ ] 年度回顾为弹层，关闭后仍停在历史页原位置
- [ ] 文案是叙述口吻，没有"统计/报表/次数表"字样

---

## 6. 易错点

| 坑 | 说明 |
|---|---|
| 月报为 0 也渲染 | 会变成一张"0 次"的报表，破坏回忆感。**空则整卡不渲染** |
| 年报单独开页 | 会打破 12 页的页面总数约定，走弹层 |
| 切换筛选不重置分页 | 会把新旧数据拼在一起。**切筛选时 `pageNo` 归 1 并清列表** |
| 历史项给操作按钮 | 历史是只读视图，要操作得进详情页 |
