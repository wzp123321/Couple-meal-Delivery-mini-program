## 一、我们收集的信息及用途

1. 微信 openid：您使用微信登录时获取，仅用于身份识别与登录，不对外展示。
2. 头像、昵称、专属称呼、纪念日：您主动设置，仅用于您和伴侣彼此的展示。
3. 带饭约定：包括点餐人、带饭人、时段、菜品、备注等，用于你们二人之间的约定流转。
4. 菜单与偏好：您记录的忌口、爱吃与备注，用于点餐时的偏好提示。
5. 打卡照片与点评：您上传的饭桌照片及三档点评，仅双方可见，构成你们的私密相册。
6. 设备与操作日志：登录凭证、登录时间等，用于安全保障与服务运行。

## 二、我们申请的权限及用途

为提供核心功能，本产品会申请以下系统权限，仅在您主动使用相关功能时调用：

- **微信登录（openid）**：用于身份识别与登录。
- **相册 / 相机**：您上传打卡照片时调用，用于饭桌相册；我们仅读取您主动选择的照片。
- **位置信息**：本产品不会主动收集您的实时位置。打卡照片的拍摄位置等元数据（EXIF）会在上传时剥离，服务器不保留。

## 三、我们如何使用信息

除上述目的外，我们不会将您的信息用于其他用途。衍生数据（如爱心值、连续投喂天数、在一起吃饭天数）仅基于您和伴侣的约定与打卡自动生成，仅你们双方可见。

## 四、信息的存储与保护

1. 您的数据存储在我们的自建服务器（数据库与图片存储），不会出售或提供给无关第三方。
2. 上传的照片会剥离拍摄位置等元数据（EXIF），避免泄露您的住址等隐私。
3. 用户生成内容（照片、文本）会经过内容安全检测，未通过的不予展示。
4. 我们采取访问控制等措施，确保只有您和您的伴侣能够查看彼此的数据。
5. **保存期限**：您的个人资料与约定在您使用期间持续保存；您注销账号后，我们将在 **15 个工作日**内删除或匿名化您的个人身份数据（解绑仅解除关系展示，不删除底层数据）。照片等用户生成内容在注销后按上述时限删除。

## 五、信息的委托处理、共享与公开

除以下情形外，我们不会向任何第三方共享或公开您的个人信息：

1. **受托处理**：为完成微信登录与内容安全检测，我们会将必要的 openid 及您上传的照片 / 文本提供给微信平台（腾讯）作为受托处理方，由其按平台规则处理；除此之外不向任何第三方提供。
2. **法定情形**：依据法律法规或有权机关的要求提供。

您的带饭约定、照片、点评等仅您和伴侣可见，不做公开、不对外展示。

## 六、个人信息出境

本产品数据存储于中国大陆境内服务器，目前不存在个人信息出境情形。

## 七、自动化决策

爱心值、连续投喂天数、在一起吃饭天数等数据，系基于您与伴侣的约定与打卡记录自动生成，仅用于情感记录与互动展示，不会对您产生重大权益影响；您可通过注销账号停止相关处理。

## 八、您的权利

1. **查阅 / 复制 / 更正 / 补充**：您可随时在「设置」中自助查看或修改您的资料与约定。
2. **删除**：您可解绑关系或删除特定数据。
3. **注销账号**：在「设置 - 注销账号」注销将真实删除您的个人身份数据（解绑不等于删除）。
4. **撤回同意**：您注销账号即视为撤回全部授权；撤回后我们将停止处理并按第四条第 5 款删除相关数据。
5. **行权响应**：我们将在 **15 个工作日**内响应您的请求。

## 九、未成年人保护

本产品为情侣之间的私密协作工具，主要面向成年用户。我们不建议未成年人使用；若我们发现或怀疑用户为未成年人，将引导其注销账号。如您是未成年人监护人，发现误注册请联系我们处理。

## 十、隐私政策的更新

我们可能不时更新本政策。更新后会在小程序内公示，您继续使用即视为同意更新内容。

- 小程序内「设置 - 反馈」入口；
- 【客服邮箱（待填）】。
